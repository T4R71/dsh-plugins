# 已知边界

本仓插件的「知道但决定不修」清单。每一条都写清了原因与影响，供使用者和维护者判断。

## 双轴插件（`dual-axis` / `dual-axis-ui`）

### B1 · 命令工具能写「写轴自定义」里被排除的路径

写轴的**基准档**（禁写 / 工作区 / 全盘）由 Windows 受限令牌在内核层执行；而 `custom` 里额外加的路径条目**只在工具层执行**。结果：用文件工具写被排除的路径会被拒，用命令写能成功。

这是全系统唯一一处「知道漏但决定不补」的地方，提示词里已如实告诉模型。

### B2 · 读轴对命令工具不生效

读轴 = 工具层围栏（`read-guard` 拦 `read` / `read_image` / `grep` / `glob`）+ 提示词。Windows 上读路径按设计没有内核实现（受限令牌只参与写类检查），因此读轴拦不住命令读取。

### B3 · 旧会话打不开

在本插件某次改动之前、被写过 `dual-axis/scopes` 会话事件的会话，在 0.1.7 里仍会被整份拒收。已决定不救。

### B4 · 与官方权限 UI 不能共存

本组合包安装时会禁用上游 `ui-permission` 行。原因是两处单占冲突（槽单占、locale 命名空间按 `(ns, locale)` 单占），第二次注册会抛错、fiber 落进 FAILED、客户端卡在 Loading plugins。想拿回官方界面必须卸载本组合包。

### B5 · 客户端那一行的键不能改

插件页配置行的键是 `@t4r71/dsh-dual-axis#dual-axis`。键不匹配时**静默不渲染、没有报错**。改包名或改 Loader 行 id 都必须同时改这个键。

## 未验证面（记账用）

- `editor.notStored`（「未存储」提示）端到端从未被触发过。
- 提交后回读文档核对的 3 秒超时**失败侧**没有实测。
- 修复写与并发写入的**竞态**只有单测。
- 子代理继承只验过「一次性进程内 spawn」，fork / continuable / 孙代未验。
- `packages/plan-tree` 与 `packages/idle-guard` 存在未声明的跨包 import（见 `COMPATIBILITY.md`），构建能否通过未验证。
