# 对上游 DSH 的补丁记录

本仓**不包含**对上游 DeepSeek Harness 源码的补丁，也不 fork 上游。这份文件只是一份台账：记录我们在本机对上游检出做过的改动，以及它们在哪、为什么改。

补丁的实体留在本机检出里（`M:\dsh`），不进本仓。这样做的原因：上游是一个持续前进的第三方仓，把补丁混进插件仓会让每次上游升级都变成解冲突。

## 台账

| 被改的上游路径 | 改动规模 | 为什么 | 与 0.1.7-rc.2 的关系 |
| --- | --- | --- | --- |
| `packages/bundle/base` | 工作树版本 577 行 vs 上游 0.1.6 版 | 组合层：把自研插件的 Loader 行拼进 profile | **0.1.7-rc.2 上游也改过同一批文件**，这是唯一会正面冲突的点 |
| `packages/bundle/web-app` | 工作树版本 533 行 | 同上，Web profile 侧 | 0.1.7-rc.2 上游版 563 行 |

（本表按已知证据填写；更完整的改动清单需要在上游检出上重新做一次逐文件对拍，见「未验证」。）

## 未验证

- 上面两行的行数取自一次对拍，对拍方法与完整改动面尚未逐文件复核。
- 除这两个组合包外是否还有别的上游改动被混在同一次工作区改动里，未分离——本机那份检出同时承载着他人并行的工作。
